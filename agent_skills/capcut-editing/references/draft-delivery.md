# 草稿检查与交付

1. 使用 get_project_info、get_tracks 和 get_track_info 核对画布、轨道、片段顺序、时间范围及素材引用。复杂工程可委派 project-reviewer。
2. 核对字幕和音效覆盖范围、静音和速度参数；不能仅根据工具调用成功声称画面效果已验证。
3. 调用 copy_project_to_jianying 前明确目标工程。该调用会触发审批，由用户批准、编辑参数或拒绝。
4. 首次交付或媒体文件有增删替换时 copy_resource=True；仅修改配置且媒体不变时可为 False。
5. 收到审批拒绝后遵循反馈，不通过其他工具重复执行被拒绝的操作。
6. 同步成功后提供实际返回的剪映路径和完成内容。草稿需要在剪映客户端打开、预览，再导出视频。
7. 在 /workspace/delivery.md 保存工程 ID、同步路径、检查结果和未完成事项；临时工程信息不写入跨会话记忆。

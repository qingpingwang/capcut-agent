# 剪辑规划

1. 从用户要求和当前素材列表确认主题、目标时长、画幅、字幕、声音要求。素材信息只有元数据时，不推测画面内容或对白。
2. 区分会话素材 ID、剪映工程 ID、轨道 ID、片段 ID，调用工具时使用正确标识。
3. 复杂任务用 write_todos 拆分成素材选择、创建工程、排列片段、添加声音字幕、检查交付。
4. 在 /workspace/edit-plan.md 记录分镜表：顺序、素材 ID、源起止时间、时间线起点、目标时长、文字和效果。时间统一注明毫秒。
5. 先创建工程，再查询或创建轨道，最后按依赖顺序添加片段。同一轨道可以复用；不要并发修改同一工程。
6. 图片需要显式时长。变速后核对目标时长；视频裁剪不得超出已知素材时长。
7. 复杂规划可委派 general-purpose 子 Agent，但工程写操作由主 Agent 执行。
8. 工具实际成功才更新任务为完成；失败保留待办并给出真实原因。
